## 0. 项目定位

丽珠集团 AI 社团/活动比赛**官方平台**，面向整个集团及旗下分公司。公司不定期举办活动与比赛，本平台是主要官网。

**双重身份**：
1. **社团工具**——展示、报名、投票、作品管理，日常运转靠它；
2. **比赛/活动载体**——每次活动以平台为统一入口。

| # | 决策 | 结论 |

## 2. 功能范围

### 2.1 核心功能（平台本体）
- **作品展示**：首页巨幕 + 作品目录 + 详情页（现有前端为门面底子，保留弧形巨幕风格）
- **活动报名**：报名表单 → 自管数据库（替代现有 Bitable 链路，Bitable 降级为管理看板）
- **作品投票**：绑定飞书登录身份，一人一票，活动期限定
- **统一管理后台**：活动管理、作品审核、报名/投票数据、权限管理，统一入口
- **登录与权限**：飞书 OAuth；角色分管理员/普通员工

### 2.2 作品资产
- **支持形态**：网站/H5、微信小程序、AIGC 视频、飞书 skill、MCP 工具等
- **提交方式**：元数据表单（标题/作者/形态/简介）+ 附件或 git 仓库链接
- **托管分级**：
  - 静态类（网页/H5）→ 平台直接托管，提交即上线
  - 动态类（需后端）→ 走 D2 容器平台部署
  - 无法托管（小程序/客户端）→ 录屏演示 + 源码包 + 展示位
- **对外分发**：官网统一目录，员工可查看、下载、本地调用

### 2.3 视觉一致性（首页）
- 官方内置「示范作品/教程模板」填充巨幕空位，兼作参赛参考
- 缩略图统一滤镜（CSS filter 处理，点开后显示原图）
- 《封面投稿规范》：构图模板 + 色板，投稿环节前置约束

## 5. 公网宣传 SOP（D5 落地）

作品需公网宣传时的人工流程（待首次实战后细化）：
1. 申请人提交公网发布申请（作品、目的、预期受众）
2. 管理员评审：内容合规、公司信息敏感性
3. 人工鉴权配置（访问控制/临时账号/限时链接）
4. 人工部署到公网环境（与内网隔离）
5. 宣传期结束后评估：保留/下线/回收
