# 活动大厅官网子页面设计规格

## 目标

将活动大厅纳入首页现有 React 官网壳层，复用顶部导航、入口行为和完整底栏；活动内容继续保持当前独立页的浅色视觉与活动数据；标题掉落字以文档坐标运行，滚动时持续下落并最终停在底栏顶部。

## 方案

- `public/app.js` 中的 `ActivitiesSection` 作为活动大厅子页面主体。
- `SiteNav` 和 `SiteFooter` 继续由 `App` 统一渲染，页面导航通过 `handleNavigate` 切换，不再跳转 `activities.html`。
- 活动主体使用 `/api/activities` 数据，保留焦点活动、近期排期、往期回顾、活动类型和参加方式。
- 活动页使用独立浅色 section 样式，不强制继承首页深色背景；导航和底栏保持官网组件的布局与功能。
- 物理标题的状态以文档坐标保存；滚动只改变渲染偏移，地面取底栏上沿，确保字符最终落到底栏前。
- 标题上方保留对白气泡，气泡文案在气泡内部水平、垂直居中；气泡作为标题装饰锚点，不参与掉落物理。
- `public/activities.html` 及其备份不删除，继续作为兼容/参考入口。

## 交互与验收

1. 首页和活动子页面均显示相同导航结构；活动大厅导航项在子页面激活。
2. 点击导航项可切换作品、活动、社区、关于、报表、报名等既有入口。
3. 活动页底部显示首页完整底栏和快捷入口。
4. 标题字符可点击/拖动；滚动期间物理状态不中断，字符最终停在底栏顶部，不停在视口中间。
5. 标题气泡显示在主字上方，文字在气泡内部居中且不因窗口尺寸溢出。
6. 活动 API 失败时展示可读空态，不影响导航和底栏渲染。
7. `public/app.js` 通过 Node 语法检查，服务端活动页入口返回 200。
