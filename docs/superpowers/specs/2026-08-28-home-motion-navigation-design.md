# 首页动效与导航优化设计

## 目标

消除作品墙首屏的卡顿与循环断带，同时让首页向下滚动时更早呈现站内入口和可浏览内容。

## 范围

- 作品墙改为稳定的无缝横向循环：每行基于完整数据副本衔接，使用 `transform` 动画，避免循环端点可见跳变。
- 降低首屏渲染压力：不再让滚动事件驱动整页频繁重渲染；作品封面使用浏览器原生延迟加载与异步解码。
- 保留悬停信息浮层、点击进入详情页，以及“悬停时墙仍继续运动”的现有行为。
- 收紧首屏垂直占用，让下方内容更快进入视野。
- 在作品墙之后增加“探索社团”入口带：作品巨幕、活动大厅、社团社区、关于我们、数据报表五张横向入口卡片；每张卡片复用原有导航逻辑。
- 顶部五项导航保留为快速跳转，不移除或改变报表页入口。

## 不做

- 不调整品牌配色、作品详情结构或报名流程。
- 不改变 `works.json` 数据结构或后端接口。
- 不处理数据报表页已知的脚本语法错误；该问题与本次首页优化分开。

## 验收

1. 28 件作品封面正常显示，循环端点无肉眼可见断带。
2. 滚动与作品墙运动流畅；悬停出现分类、标题、作者与简介，墙面持续运动。
3. 点击作品仍进入详情页。
4. 首页向下滑动可见五张入口卡片，全部能正确跳转。
5. 桌面和手机宽度下布局不溢出，浏览器控制台无新增错误。
